## NEVER 6 — json.dump ohne atomic write

**Risiko:** Daten-Korruption bei Stromausfall (Pico USV schuetzt nur kurz)
**Fix-Pattern:**
```python
# VORHER (unsicher):
with open(path, 'w') as f:
    json.dump(data, f, indent=2)

# NACHHER (sicher):
import tempfile, os
fd, tmp = tempfile.mkstemp(dir=os.path.dirname(path), suffix=".tmp")
try:
    with os.fdopen(fd, 'w') as f:
        json.dump(data, f, indent=2, ensure_ascii=False)
    os.replace(tmp, path)
except OSError:
    with open(path, 'w') as f:  # NTFS-Fallback
        json.dump(data, f, indent=2, ensure_ascii=False)
    try: os.unlink(tmp)
    except OSError: pass
```
